# 在浏览器中输入`www.baidu.com`后执行的全部过程？

1. **域名解析**（域名 www.baidu.com 变为 ip 地址）。
	搜索 **浏览器 DNS缓存**（维护一张域名与IP的对应表）；
	若没有，则搜索**操作系统 DNS缓存**（维护一张域名与IP的对应表）；
	若没有，则搜索**操作系统 Hosts文件**（维护一张域名与IP的对应表）。

	若都没有，则找 tcp/ip 参数中设置的首选 DNS 服务器，即 **本地 DNS 服务器**（**递归查询**）
	
	本地DNS服务器查询自己的 **DNS缓存**，如果没有，则进行迭代查询。
	- **根服务器**：管理各类顶级域名（如 `.com`、`.cn`）的服务器地址
	- **顶级域名服务器**：管理所有以 `.com` 结尾的域名。
	- **权威域名服务器**：存储着 `www.baidu.com` 最终对应的 IP 地址
	将本地DNS服务器将IP返回给操作系统，同时缓存IP。
	
2. **建立连接（TCP 与 TLS）**：发起 TCP 的三次握手 和 TLS握手，建立连接。浏览器会以一个随机端口（1024-65535）向服务端的 web 程序 80 端口发起 tcp 的连接。
3. **发送 HTTP 请求**：建立 tcp 连接后发起 http 请求。
4. **服务器处理与相应**：服务器 web 应用程序收到 http 请求后，就开始处理请求，处理之后就返回给浏览器 html 文件。
5. **浏览器渲染页面**：渲染过程中遇到外部资源时，会再次发起网络请求加载，并呈现给用户
