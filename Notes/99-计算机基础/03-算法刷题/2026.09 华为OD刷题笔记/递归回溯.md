
### 组合：`start`

```python
def backtrack(start, path):

    if len(path) == k:
        return

    for i in range(start, n):
        path.append(i)

        backtrack(i + 1, path)

        path.pop()
```

核心思想是：

> **后面的选择不能回头。**

因此：

```
1,2
```

出现以后不会再出现：

```
2,1
```

### 排列：`used`

```python
def backtrack(path, used):

    if len(path) == k:
        return

    for i in range(n):
        if used[i]:
            continue

        used[i] = True
        path.append(i)

        backtrack(path, used)

        path.pop()
        used[i] = False
```

核心思想是：

> **每一层都可以选择任意还没使用过的数字。**

所以：

```
1 → 2
```

和：

```
2 → 1
```

都会被搜索。
