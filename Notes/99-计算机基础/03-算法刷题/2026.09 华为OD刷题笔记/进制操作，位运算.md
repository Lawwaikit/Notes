
## 位运算

> 每一节都是一种**独立的操作方式**，按 `###` 三级标题划分，可直接用目录跳转查找。
> 每个三级标题下：一句话说明 → 可运行代码块 → 要点提示。

### 速查表

| 想做的事 | 写法 | 备注 |
| --- | --- | --- |
| 获取第 n 位 | `(x >> n) & 1` | 结果是 0 或 1 |
| 检查第 n 位是否为 1 | `(x & (1 << n)) != 0` | 结果是 bool |
| 获取从 start 开始的 count 位 | `(x >> start) & ((1 << count) - 1)` | 提取 bit 字段 |
| 造“低 N 位全 1”的掩码 | `(1 << N) - 1` | N=5 → `0b11111` |
| 只保留低 N 位 | `x &= (1 << N) - 1` | 高位清零 |
| 第 n 位置 1 | `x \|= (1 << n)` | 打开某位 |
| 第 n 位清 0 | `x &= ~(1 << n)` | 关闭某位 |
| 第 n 位翻转 | `x ^= (1 << n)` | 状态取反 |
| 乘以 2ⁿ | `x << n` | 正整数适用 |
| 整除 2ⁿ | `x >> n` | 正整数适用 |
| 按位取反 | `~x` | Python 中等于 `-x - 1` |

## 一、基础运算符

### 按位与 `&`

两个位都为 1 时结果才为 1。常用于**提取 / 清除 / 判断**某些位。

```python
result = 0b1010 & 0b1100

# 1010
# 1100
# ----
# 1000   ->  8
# 只有“两个都是 1”的位置才是 1。
```

### 按位或 `|`

只要有一个是 1，结果就是 1。常用于**把某些位设置为 1**。

```python
result = 0b1010 | 0b1100

# 1010
# 1100
# ----
# 1110   ->  14
# 只要有一个是 1，结果就是 1。
```

### 按位异或 `^`

相同为 0，不同为 1。常用于**判断两个 bit 是否不同 / 状态切换**。

```python
result = 0b1010 ^ 0b1100

# 1010
# 1100
# ----
# 0110   ->  6
# 相同 -> 0 ，不同 -> 1
# 经典性质：a ^ a = 0 ，a ^ 0 = a（可用于“找出只出现一次的数”）
```

### 按位取反 `~`

Python 整数不是固定 32 位，记住公式 **`~x == -x - 1`**。

```python
result = ~137   # -138

# ~x == -x - 1
# 不要理解成“转成 32 位再全部翻转”，Python 没有固定位宽。
```

### 左移 `<<`

对正整数可理解为 **`number * 2ⁿ`**。

```python
result = 3 << 2

# 3 = 0011
# 0011 << 2 = 1100   ->  12
# number << n  ≈  number * 2**n
```

### 右移 `>>`

对正整数可理解为 **`number // 2ⁿ`**；负数需注意 Python 的负数右移规则（向下取整，高位补符号位）。

```python
result = 12 >> 2

# 12 = 1100
# 1100 >> 2 = 0011   ->  3
# number >> n  ≈  number // 2**n
```

## 二、读取 / 提取

### 获取某一位（bit）

把目标位右移到最低位，再用 `& 1` 取出，结果是 0 或 1。

```python
number = 0b11010110
bit_index = 2

bit_value = (number >> bit_index) & 1

# 11010110 >> 2  = 00110101
# 00110101 & 00000001 = 00000001
# => bit_value = 1
```

### 检查某一位是否为 1

与上一种写法功能相同，但**语义更像“这一位有没有被设置”**，结果直接是布尔值。

```python
number = 0b11010110
bit_index = 2

is_set = (number & (1 << bit_index)) != 0

# 11010110
# &00000100
# ----------
# 00000100  != 0   =>  第 2 位是 1
```

### 获取连续的多个 bit

套路：**先右移到最低位，再与上掩码**。

```python
number = 0b11010110
start_bit = 1     # 起始位置
bit_count = 2     # 要取几位

mask = (1 << bit_count) - 1
field_value = (number >> start_bit) & mask

# 11010110 >> 1 = 01101011
# mask = (1<<2)-1 = 00000011
# 01101011
# &00000011
# ----------
# 00000011   =>  field_value = 3
# 记忆：value = (number >> 起始位置) & 掩码
```

### 获取固定长度字段（掩码写死）

起始位置和长度都固定时，掩码可以直接写成常量。

```python
number = 0b110101101111

field_value = (number >> 4) & 0b1111   # 取 bit4 ~ bit7

# 110101101111 >> 4 = 000011010110
# 000011010110
# &000000001111
# --------------
# 000000000110   =>  field_value = 6
```

### 提取任意字段（通用写法）

上面两种的统一公式，解析协议 / 报文时最常用：

> `field = (packet >> 起始位置) & ((1 << 位数) - 1)`

```python
packet = 0b110101101111
field_start_bit = 4
field_bit_count = 4

field_mask = (1 << field_bit_count) - 1
field_value = (packet >> field_start_bit) & field_mask

# 两步理解：
# 1. >> 4      把 bit4 移到 bit0
# 2. & mask    只保留这 4 位
```

## 三、设置 / 修改

### 把某一位设置为 1

用 `|=` 打开某一位，**只影响目标位，其它位不变**。

```python
number = 0b1000
number |= (1 << 2)

# 1000
# |0100
# ----
# 1100   =>  number = 12
```

### 把某一位设置为 0

用 `&= ~(1 << n)` 关闭某一位，**只影响目标位，其它位不变**。

```python
number = 0b1110
number &= ~(1 << 2)

# 1 << 2 = 0100 ，~(0100) = ...1011
# 1110
# &1011
# ----
# 1010   =>  number = 10
```

### 翻转某一位

异或同一个掩码两次会回到原值，所以 `^` 天然适合做**开关切换**。

```python
number = 0b1010
number ^= (1 << 1)

# 1010
# ^0010
# ----
# 1000   =>  number = 8
# 再执行一次同样的 ^= 就会变回 1010
```

### 只保留低 N 位

`number &= mask` 的含义就是：**只保留 mask 中为 1 的那些位**，其余清零。

```python
number = 0b101101011001
valid_bit_count = 5

number &= (1 << valid_bit_count) - 1

# 101101011001
# &000000011111
# ------------
# 000000011001   =>  number = 0b11001 = 25
```

## 四、掩码构造

### 创建“低 N 位全是 1”的掩码

`(1 << N) - 1` 是位运算里**最高频的构造**，务必形成肌肉记忆。

```python
bit_count = 5
mask = (1 << bit_count) - 1

# 1 << 5    = 00100000
# 00100000 - 1 = 00011111  =>  mask = 0b11111 = 31
# N = 1 -> 00001      N = 2 -> 00011      N = 3 -> 00111
# N = 4 -> 01111      N = 5 -> 11111
```

## 五、进制表示与类型转换

### 整型的进制字面量

同一个数 214 的四种写法，类型都是 `int`，没有“二进制整型”这种类型。

```python
binary      = 0b11010110   # 二进制，前缀 0b / 0B
octal       = 0o326        # 八进制，前缀 0o / 0O
decimal     = 214          # 十进制，直接写
hexadecimal = 0xD6         # 十六进制，前缀 0x / 0X

print(binary, octal, decimal, hexadecimal)   # 214 214 214 214
print(type(binary))                          # <class 'int'>

# 前缀只是“书写方式”，存进内存后都是普通的 int。
# 提高可读性：0x_FF_FF 、0b_1010_1010（下划线会被忽略）
```

### 整型 → 进制字符串

`bin / oct / hex` 带前缀；`format` / f-string 不带前缀、可补零、可定宽。

```python
n = 255

bin(n)   # '0b11111111'   带前缀
oct(n)   # '0o377'
hex(n)   # '0xff'

format(n, 'b')   # '11111111'   不带前缀
format(n, 'o')   # '377'
format(n, 'x')   # 'ff'   小写
format(n, 'X')   # 'FF'   大写
format(n, 'd')   # '255'  十进制

f'{n:08b}'    # '11111111'     补零到 8 位（不含前缀）
f'{n:#010b}'  # '0b11111111'   补零到总宽 10（含 0b 两位）
f'{n:#04x}'   # '0xff'
f'{n:>8d}'    # '     255'     右对齐，宽度 8
```

### 进制字符串 → 整型

统一入口 `int(字符串, 进制)`。

```python
int('11111111', 2)       # 255   01 字符串 -> int
int('0b11111111', 2)     # 255   带 0b 前缀也能吃
int('0b11111111', 0)     # 255   base=0：按前缀自动识别
int('0o377', 0)          # 255
int('0xFF', 16)          # 255   0xFF 字符串 -> int
int('FF', 16)            # 255   不带前缀也行
int('0xFF', 0)           # 255
int('255')               # 255   缺省就是十进制
int('1_000', 0)          # 1000  下划线分隔符，base=0 可用
```

### 转换的坑

```python
int('010', 0)   # ValueError！base=0 不允许十进制前导零
int('010')      # 10       默认十进制，前导零没事

bin(-5)         # '-0b101'   负号在前缀外面，不是补码
# 想要 32 位补码表示：
format(-5 & 0xFFFFFFFF, '032b')   # '11111111111111111111111111111011'

# 去掉前缀：bin(n)[2:] / hex(n)[2:]
# 更推荐 format(n, 'b')，不用切片、还能补零
```

## 六、长除法：超长整数字符串转进制

### 为什么需要长除法

Python 的 `int` 是**任意精度**，`int(超长字符串)` 直接就能装下，所以 Python 里其实**不需要**手写长除法：

转进制的本质就是，对于num和目标进制target，重复获取到
```
商 num//target 和 余数 num%target
```

余数 是目标进制数的低位，商 是剩下的数，需继续循环
但是超长数字不能直接做数学运算，所以需要长除法模拟


### 核心：字符串除以一个小整数

一次长除法 = 从高位到低位逐位“带余数下移”，返回 `(商, 余数)`。

```python
def divmod_str(num_str: str, base: int) -> tuple[str, int]:
    """十进制字符串 num_str 除以 base，返回 (商字符串, 余数)。"""
	quotient_chars = []  #存放商
    remainder = 0 # 余数
    for ch in num_str:
        cur = remainder * 10 + int(ch)     # 上一位余数 × 10 + 当前位
        quotient_chars.append(str(cur // base))
        remainder = cur % base
    return (''.join(quotient_chars).lstrip('0') or '0'), remainder

divmod_str('1234', 16)   # ('77', 2)     1234 = 77 * 16 + 2
divmod_str('77', 16)     # ('4', 13)
divmod_str('4', 16)      # ('0', 4)
```

`divmod_str('1234', 16)` -> `('77', 2)` 这一步的手算过程：

```text
千位 1 : cur = 0*10+1  = 1    -> 商 0，余 1
百位 2 : cur = 1*10+2  = 12   -> 商 0，余 12
十位 3 : cur = 12*10+3 = 123  -> 商 7，余 11
个位 4 : cur = 11*10+4 = 114  -> 商 7，余 2
商 = "0077" 去前导零 -> "77" ，余数 = 2
即1234=77*16+2 2就是最低位了
```

### 完整版：任意进制字符串互转

把上面的“逐位除法”从十进制推广到任意源进制，再反复除到 0、倒序取余数即可。

```python
DIGITS = '0123456789abcdefghijklmnopqrstuvwxyz'   # 最高支持 36 进制

def char_to_value(ch: str) -> int:
    return DIGITS.index(ch.lower())

def divmod_big(num_str: str, src_base: int, dst_base: int) -> tuple[str, int]:
    """src_base 进制的超长字符串 num_str 除以 dst_base，返回 (商, 余数)。
    商仍然是 src_base 进制的字符串。"""
    quotient_chars = []
    remainder = 0
    for ch in num_str:
        cur = remainder * src_base + char_to_value(ch)
        quotient_chars.append(DIGITS[cur // dst_base])
        remainder = cur % dst_base
    return (''.join(quotient_chars).lstrip('0') or '0'), remainder

def convert_base(num_str: str, src_base: int, dst_base: int) -> str:
    """任意进制字符串 -> 任意进制字符串（2 <= base <= 36）。"""
    num_str = num_str.lstrip('0') or '0'
    if num_str == '0':
        return '0'
    result = []
    while num_str != '0':
        num_str, r = divmod_big(num_str, src_base, dst_base)   # 反复除
        result.append(DIGITS[r])                                # 收集余数
    # result append的顺序是从低位到高位，所以需要反转一下
    return ''.join(reversed(result))                            # 余数倒序

convert_base('1234', 10, 16)              # '4d2'
convert_base('ff', 16, 10)                # '255'
convert_base('11010110', 2, 10)           # '214'
convert_base('7fffffffffffffff', 16, 10)  # '9223372036854775807'
convert_base('9' * 200, 10, 16)           # 超长数照样能转，不依赖大整数库
```

### 手算演示：1234 → 十六进制

```text
1234 ÷ 16 = 77  余 2   -> 记 2
  77 ÷ 16 = 4   余 13  -> 记 d
   4 ÷ 16 = 0   余 4   -> 记 4
商变成 0，停止
此时余数按顺序记录[2,d,4]把余数倒序拼接：4 d 2  =>  0x4d2
```

要点：**反复“除以目标进制取余”，最后把余数倒序排列**。先算出来的是最低位。
