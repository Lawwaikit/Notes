# AI回答 01背包
这道题**本质上确实可以用 0/1 背包的思路做**，但它和普通 0/1 背包有一个关键区别：**一个订单能不能选，不仅取决于总工作天数，还取决于截止日期**。

最核心的思路是：**把每个订单看成一个物品，把“工作天数”看成背包重量，把“收益”看成价值，然后按照截止日期排序，再做 0/1 背包。**

### 1. 先把题目抽象一下

假设有这些订单：

```text
订单     工作天数     截止日期     收益
A          3            4          50
B          2            2          40
C          4            7          70
D          2            6          30
```

作家只能串行工作，所以如果选择：

```text
B → A → C
```

那么完成时间分别是：

```text
B：2天
A：2 + 3 = 5天
C：5 + 4 = 9天
```

C 的截止日期是 7，所以这个方案非法。

这里就会发现一个问题：**订单的选择不仅仅是“总天数不超过某个值”，每个订单还有自己的 deadline。**

---

### 2. 为什么要按照截止日期排序？

这是这道题最关键的一步。

把所有订单按照 `deadline` 从小到大排序：

```python
orders.sort(key=lambda x: x[1])
```

假设：

```text
A：3天，deadline=4，收益50
B：2天，deadline=2，收益40
C：4天，deadline=7，收益70
D：2天，deadline=6，收益30
```

排序后：

```text
B：2天，deadline=2，收益40
A：3天，deadline=4，收益50
D：2天，deadline=6，收益30
C：4天，deadline=7，收益70
```

这样做之后，我们就可以让 DP 的状态表示：

> 在已经考虑过的订单中，选择一些订单，总工作时间为 `t` 时，能够获得的最大收益。

关键是，当我们准备加入某个订单时，只需要判断：

```python
t + duration <= deadline
```

如果成立，这个订单就可以安排在当前订单之后完成。

---

### 3. DP 状态

定义 `dp[t]` 表示工作 `t` 天时能够获得的最大收益。

例如：

```text
dp[0] = 0
dp[1] = ...
dp[2] = ...
dp[3] = ...
```

那么，状态转移方程：

```python
dp[t] = max(dp[t], dp[t-duration] + profit)
```

但是这里必须满足：

```python
t <= deadline
```

因为当前订单完成时间不能超过它的截止日期。

---

### 4. 这就是 0/1 背包

标准 0/1 背包你应该记得这个模板：

```python
for item in items:
    for j in range(capacity, weight - 1, -1):
        dp[j] = max(dp[j], dp[j - weight] + value)
```

这里：

```text
weight → 订单持续天数 duration
value  → 订单收益 profit
capacity → 最大允许工作天数 
```

但是本题没有一个统一的 `capacity`。

每个订单自己的 `deadline` 就相当于当前订单的容量限制。

所以变成：

```python
for duration, deadline, profit in orders:
    for t in range(deadline, duration - 1, -1):
        dp[t] = max(dp[t], dp[t - duration] + profit)
```

不过这里有一个细节：**这样写之前必须按照 deadline 从小到大排序。**

完整代码：

```python
def max_profit(orders):
    # orders[i] = [持续天数, 截止日期, 收益]

    # 按截止日期从小到大排序
    orders.sort(key=lambda x: x[1])

    max_deadline = max(x[1] for x in orders)

    # dp[t]：总工作时间为 t 时的最大收益
    dp = [0] * (max_deadline + 1)

    for duration, deadline, profit in orders:

        # 逆序遍历，保证每个订单只能选择一次
        for t in range(deadline, duration - 1, -1):

            dp[t] = max(
                dp[t],
                dp[t - duration] + profit
            )

    return max(dp)
```

### 5. 为什么一定要倒序？

这和你之前问过的 0/1 背包完全一样。

假设一个订单：

```text
duration = 3
profit = 50
```

如果正序：

```python
for t in range(duration, deadline + 1):
```

那么：

```text
dp[3] = dp[0] + 50
dp[6] = dp[3] + 50
```

于是同一个订单可能被使用两次。

所以 0/1 背包必须：

```python
for t in range(deadline, duration - 1, -1):
```

这样 `dp[t - duration]` 还是**处理当前订单之前的状态**，因此一个订单最多使用一次。

---

### 6. 为什么排序后就能保证订单顺序合法？

这个地方是本题最容易疑惑的地方。

假设我们选择了：

```text
订单 A：duration=3，deadline=5
订单 B：duration=2，deadline=7
订单 C：duration=4，deadline=10
```

按照 deadline 排序：

```text
A → B → C
```

如果 DP 最后选择了三个订单，那么它实际上对应的工作顺序就是：

```text
A → B → C
```

完成时间：

```text
A：3
B：5
C：9
```

分别满足：

```text
3 <= 5
5 <= 7
9 <= 10
```

因此合法。

更重要的是，对于**任意一组被选择的订单**，如果它存在一种合法的排列，那么把它们按照 deadline 从小到大排列后，也一定可以合法完成。

这是这道题能够转化成背包的关键。

---

### 7. 用一个完整例子理解

假设：

```python
orders = [
    [3, 4, 50],
    [2, 2, 40],
    [4, 7, 70],
    [2, 6, 30]
]
```

按照 deadline 排序：

```text
[2, 2, 40]
[3, 4, 50]
[2, 6, 30]
[4, 7, 70]
```

考虑：

```text
B + A
```

总工作时间：

```text
2 + 3 = 5
```

A 的 deadline 是 4，所以：

```text
5 > 4
```

不能同时选择。

考虑：

```text
B + D
```

总工作时间：

```text
2 + 2 = 4
```

D 的 deadline 是 6，因此合法：

```text
B：2 <= 2
D：4 <= 6
```

收益：

```text
40 + 30 = 70
```

考虑：

```text
B + C
```

总时间：

```text
2 + 4 = 6
```

C deadline = 7：

```text
6 <= 7
```

收益：

```text
40 + 70 = 110
```

所以最终可以得到至少 `110` 的收益。

### 8. 你可以把这道题记成一个特殊的 0/1 背包

普通 0/1 背包：

```text
物品重量 = weight
物品价值 = value
背包容量 = capacity
```

这道题：

```text
订单耗时 = weight
订单收益 = value
订单截止日期 = 当前订单的 capacity
```

因此套路就是：

```text
按照 deadline 从小到大排序
→ dp[t] 表示工作 t 天的最大收益
→ 对每个订单做 0/1 背包
→ t 不能超过当前订单 deadline
→ t 必须倒序
→ 最后取 max(dp)
```

对应代码最值得你记住的是这一段：

```python
orders.sort(key=lambda x: x[1])

dp = [0] * (max_deadline + 1)

for duration, deadline, profit in orders:
    for t in range(deadline, duration - 1, -1):
        dp[t] = max(dp[t], dp[t - duration] + profit)

answer = max(dp)
```

**和你之前做的“菌子加工”那道 0/1 背包题相比，本题真正新增的知识点只有一个：`deadline` 不同，所以先按照 deadline 排序，然后把当前订单的 deadline 当成这一轮 DP 的上界。**

# 我的理解：01背包+dp

对于每个订单，都有 用 和 不用 两个选项
定义`dp[t]` 截止日期为t时获取的最大收益

一个经典的带图解 01背包 文章：[ 0-1 背包问题](https://www.hello-algo.com/chapter_dynamic_programming/knapsack_problem/#4)

```
物品重量 weight → 订单持续天数 duration
物品价值 value  → 订单收益 profit
背包总容量 capacity → 最大允许工作天数 
```

```python
def max_profit(orders):
	# 假设orders 已经按照截止日期升序排序
	orders = []
    max_t = max(x.dealline for x in orders)

    # dp[t]：总工作时间为 t 时的最大收益
    dp = [0] * (max_t + 1)

    for order in orders:
		duration = order.duration
		deadline = order.deadline
		profit = order.profit
		
        # 逆序遍历，保证每个订单只能选择一次
        for t in range(deadline, duration - 1, -1):
	        # 遍历范围 [deadline, duration) 倒序
            dp[t] = max(
                dp[t],
                dp[t - duration] + profit
            )
    return max(dp)
```

在背包问题中，影响是否装进背包里的是容量，在订单里，在于订单是否超出截止日期

对于每个订单，不一定在截止日期才会完成，
开始时间：`[0, order.deadline-order.duration]` 在这个范围皆可
结束时间:  `[order.duration, order.deadline]` 在这个范围皆可
所以for循环遍历的是 所有可能的结束时间

**为什么要倒序？**
其实我们简化了dp，因为每个订单，都有用与不用的选择，每个订单最多只能用一次
完整的dp应该是二维的
`dp[i][t]` 表示已遍历了前 i 个订单，截止日期为t 的最大收益，最终我们需要`dp[n][max_t]`
我们现在只使用了一维，相当于简化了i，所以dp是对于每个订单，滚动`t`更新

正序可能会出现，该订单的收益 被多次更新到dp里面
现在 all dp = 0，
假如第一个订单，订单的duartion=3, ddl=9, profit=100, 结束时间可以落在[3,9]

```python
# 正序
for t in range(3, 9+1):
	dp[t] = max(
		dp[t],
		dp[t - duration] + profit
	)
	
会出现 
dp[3]=dp[0]+100=100
dp[4]=dp[1]+100=100

dp[9]=dp[6]+100=300

# 倒序
```

# 题解：普通dp -> 稀疏dp
直接开 `dp[max_t]` 会出现超过内存的情况
可以通过只记录关键时间节点，稀疏压缩保存状态。并且维护保存状态`时间递增，收益严格递增`进一步减少保存状态。例如`(8 23) (10, 21) 那么 (10,21)永远不会成为最优解`

```python
def solve(duration, deadline, profit):
	# 省去一部分.....
    # orders 按截止时间从小到大处理
    
    # states记录了一些组合方案，不知道订单具体怎么组合，但是记录组合的(总耗时, 最大收益)
	states = [(0, 0)]
    for order in orders:
        next_states = states.copy()
        # 尝试选择当前订单
        for time, profit_value in states:
			new_time = time + order.duration
			if new_time <= order.deadline:  # 选择该订单不超过截止日期
                next_states.append((new_time, profit_value + order.profit))
		
        # 按总耗时排序，相同时间只保留最大收益
        # 假设 next_states=[(3, 50) (4, 70) (5, 80), (5, 70)]
        # 对于前三个，cur会append，=[(3, 50) (4, 70) (5, 80)]
        # 对于第四个，cur[-1]=(5, 80) (time, profit_value)=(5, 70)
        next_states.sort()
        cur = []
        for time, profit_value in next_states:
            if cur and cur[-1][0] == time:
                cur[-1] = (time, max(cur[-1][1], profit_value))
            else:
                cur.append((time, profit_value))
		
        # 删除被支配状态
        # 如果已有更少/相等的时间获得了更高/相等的收益，
        # 当前状态就永远不会成为最优解
	    
	    # 前面cur是先严格时间递增，保留收益最高的
	    # 现在是看有没有存在 方案对{a, b} a时间少又收益高的,丢弃b
		# 假设 cur=[(3, 50),(4, 70),(5, 80),(6,20),(7,90)] 时间递增
		# 前三个,收益递增,states.append 第四个收益没有达到递增，丢弃方案
        states = []
        max_profit = -1
        for time, profit_value in cur:
            if profit_value > max_profit:
                states.append((time, profit_value))
                max_profit = profit_value

    ans = 0
    for time, profit_value in states:
        ans = max(ans, profit_value)

    return ans
```

# 我的代码
```python
class Order:
    def __init__(self, duartion, deadline, profit):
        self.duartion = duartion
        self.deadline = deadline
        self.profit = profit


def solve(times, deadlines, profits):
    n = len(times)
    orders = []
    for i in range(n):
        orders.append(Order(
            times[i], deadlines[i], profits[i]
        ))
    # 按照截止日期升序排序订单
    orders.sort(key=lambda x: x.deadline)

    # states记录了一些组合方案,不知道订单具体怎么组合,但是记录组合的(总耗时,最大收益)
    states0 = [(0, 0)]    
    for order in orders:
        duartion = order.duartion
        deadline = order.deadline
        profit = order.profit

        states1 = states0.copy()
        # 尝试选择当前订单
        for t, p in states0:
            if t + duartion <= deadline:  # 选择该订单不超过截止日期
                states1.append((t+duartion, p+profit))
        
        # 相同时间保留最大收益(这里可以用双指针,滑动相同的时间区间t,保留最大值)
        states1.sort()
        states2 = []
        for t, p in states1:
            if states2 and states2[-1][0] == t: # 相同时间
                states2[-1] = (t, max(states2[-1][-1], p))
            else:
                states2.append((t, p))
        
        # 删除被支配状态，保证收益递增
        states3 = []
        max_p = -1
        for t, p in states2:
            if p > max_p:
                states3.append((t, p))
                max_p=p
        states0 = states3
    
    return states0[-1][1]
```
