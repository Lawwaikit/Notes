# 知识：
IPv4 地址本质上是一个 **32 位二进制数**，通常为了方便阅读，写成 4 段十进制数字：`192.168.1.0`

4 段分别对应 8 位：
```
192       .168       .1         .0
11000000  .10101000  .00000001  .00000000
   8位       8位        8位        8位
每一段的范围都是 `0~255`，因为 8 位二进制最多表示：

00000000 = 0
11111111 = 255
```

因此 `192.168.1.0` 本质上就是一个 32 位整数。

### 掩码：
```
192.168.1.0/24  
这里的 /24 就叫 CIDR 前缀长度，也可以理解成 掩码长度。

它表示 IPv4 的 32 位中：
前 24 位 = 网络部分
后 8 位  = 主机部分

因此
掩码长度 = 24
主机位   = 32 - 24 = 8
两者关系永远是：主机位 + 掩码长度 = 32

对应的二进制掩码就是：
11111111 11111111 11111111 00000000

转换成十进制就是：
255.255.255.0
```

### 主机位：
假设：
```
地址：192.168.1.0/24，掩码长度24
那么 主机位 = 32-24 = 8

这 8 位理论上有 2^8 = 256 个主机
但是在一个普通 IPv4 子网中，通常有两个地址不能分配给普通主机
全 0 → 网络地址
全 1 → 广播地址

所以可用主机数：2^主机位 - 2

也就是 2^8 - 2 = 254
因此 192.168.1.0/24
网络地址：192.168.1.0
可用主机：192.168.1.1 ~ 192.168.1.254
广播地址：192.168.1.255
```



# 我的代码：
```python
def addr_str_to_int(addr_str):
    lst = list(map(int, addr_str.split('.')))
    ans = 0
    for ele in lst:
        ans = (ans << 8) + ele
    return ans

def int_to_addr_str(num):
    ans = []
    for i in range(4):
        ans.append(str(num & 0xFF))
        num = num >> 8
    ans = reversed(ans)
    return ".".join(ans)

def get_need_host(need):
    # 输入需求的主机数量，返回主机位
    host = 2 # 主机位1
    while (1<<host) - 2 < need:
        host += 1
    return host

def solve(addr_str, n, arr):
    # CIDR: 192.168.1.0/24 
    # 192.168.1.0 -> addr
    # 24        -> mask 掩码长度
    # 32-24=8   -> host 主机长度
    # 2**8-2    -> host_num 主机数量

    init_addr, init_mask = tuple(addr_str.split('/'))
    init_mask = int(init_mask)
    init_host = 32 - init_mask   # 主机位
    if init_host < 2:  # 主机位不足2位
        return []

    # host 即为需要的主机位长度
    host = get_need_host(max(arr))
    # 需要主机位 不能大于 主网段主机位
    if host > init_host:
        return []
    
    # 假设：原来有8位主机位，现在需要6位，剩下2位拿来编号子网。
    #      2个二进制位有 2**2=4种组合，因此能划分4个等长子网。
    subnet_num = 2**(init_host - host)
    if subnet_num < n: # 子网数量不够分给部门
        return []

    # 开始分配
    ans = []

    start_num = addr_str_to_int(init_addr)    # 起始地址
    subnet_size = 1<<host   # 子网的跨度
    for i in range(n):
        each_addr_num = start_num + i * subnet_size
        each_addr = int_to_addr_str(each_addr_num)
        ans.append(f'{each_addr}/{32-host}')

    return ans


# print('测试:', addr_str_to_int('192.168.1.0'))
# print('测试:', int_to_addr_str(3232235776))

addr_str = input()
n = int(input())
arr = list(map(int, input().split(' ')))
ans = solve(addr_str, n, arr)
if ans:
    print(",".join(ans))
else:
    print()
```
