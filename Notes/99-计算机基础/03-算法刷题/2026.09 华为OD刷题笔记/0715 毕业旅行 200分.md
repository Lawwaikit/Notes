适用于**单源最短路径问题**

## 堆(最小堆，最大堆)
`heapq` 本质上是 Python 的**最小堆**，核心特点是：每次 `heappop()` 都取出当前最小元素。
```python
import heapq

# 创建最小堆
heap = []

# 1. 插入元素
heapq.heappush(heap, x)

# 2. 取出最小元素，并删除
x = heapq.heappop(heap)

# 3. 查看最小元素，不删除
x = heap[0]

# 4. 将列表直接转换成堆
heapq.heapify(nums)

# 5. 替换堆顶：先删除最小值，再插入新值
heapq.heapreplace(heap, x)

# 6. 先比较，再决定是否替换堆顶
heapq.heappushpop(heap, x)

# 7. 取最小的 k 个元素
result = heapq.nsmallest(k, nums)

# 8. 取最大的 k 个元素
result = heapq.nlargest(k, nums)
```

### 一个很重要的用法：存元组

`heapq` 可以直接存元组，而且按照元组的第一个元素排序。
如果第一个元素相同，Python 会继续比较第二个元素

```python
heapq.heappush(heap, (5, "A"))
heapq.heappush(heap, (2, "B"))
heapq.heappush(heap, (8, "C"))

print(heapq.heappop(heap))
# (2, "B")
```

### 什么时候用到堆
#### ① 最短路径：Dijkstra
#### ② Top K 问题
```python
# 给定 100 万个数字，找最大的 10 个
heap = []
for x in nums:
    if len(heap) < k:
        heapq.heappush(heap, x)
    elif x > heap[0]:
        heapq.heapreplace(heap, x)
```
#### ③ 合并多个有序序列
例如有：
```python
A = [1, 4, 7]
B = [2, 5, 8]
C = [3, 6, 9]
```
要求合并成一个有序数组。
可以把每个数组当前最小值放进堆：
```python
heap = [
    (1, A),
    (2, B),
    (3, C)
]
```
每次取出最小值，然后把对应数组的下一个元素放进去。

这种题的典型关键词是：

**合并 K 个有序数组、合并 K 个有序链表、多路归并。**
#### ④ 优先队列 / 任务调度

例如：

> 有很多任务，每个任务都有优先级，每次执行优先级最高的任务。

可以使用堆。

如果数字越小优先级越高：

```python
heapq.heappush(heap, (priority, task))
priority, task = heapq.heappop(heap)
```

如果数字越大优先级越高，可以把优先级取负：

```python
heapq.heappush(heap, (-priority, task))
```

典型题目包括：

**任务调度、事件处理、优先级队列、模拟系统。**

---

#### ⑤ 最小代价 / 每次选择当前最小值

有一类题目的特点是：

> 每一步都要从当前所有候选方案中选择最小的一个。

例如经典的“合并石头”：

```
2 3 4 6
```

每次取最小的两个合并：

```
2 + 3 = 5
4 + 5 = 9
6 + 9 = 15
```

这里就非常适合最小堆：

```python
heapq.heapify(nums)

while len(nums) > 1:
    a = heapq.heappop(nums)
    b = heapq.heappop(nums)

    heapq.heappush(nums, a + b)
```

这种题通常属于**贪心 + 堆**。

---

#### ⑥ 数据流中的中位数

如果数字不断加入：

```python
5 → 2 → 8 → 10 → 3 → ...
```

要求随时查询当前中位数，可以使用**两个堆**：

```python
大顶堆：保存较小的一半
小顶堆：保存较大的一半
```

但 Python 的 `heapq` 只有小顶堆，所以大顶堆通常通过存负数模拟：

```python
max_heap = []   # 存 -x
min_heap = []   # 存 x
```

这是 `heapq` 比较经典的进阶应用。
## 理解后代码
```python
import heapq

def solve(n, m, w, lines):
    # n城市数量 m路线数量 w最大预算

    # 出发城市编号为 1，目的地城市编号为 n

    # n*?二维记录cost
    graph = [[] for _ in range(n+1)]
    for line in lines:
        u, v, cost = tuple(line)
        graph[u].append((v, cost))

    INF = 100000
    dist = [INF]*(n+1)
    dist[1] = 0
    hq = [(0, 1)]   # 0费用, 从1城市到1

    while hq:
        cost, u = heapq.heappop(hq)

        if cost > dist[u]:
            # 过时节点
            continue
        
        for v, c in graph[u]:
            if dist[u] + c < dist[v]:
                dist[v] = dist[u] + c
                heapq.heappush(hq, (dist[v], v))

    # 判断预算
    if dist[n] <= w:
        return dist[n]
    return -1


n, m, w = map(int, input().split(' '))

lines=[]
for i in range(m):
    lines.append(list(map(int, input().split(' '))))

ans = solve(n, m, w, lines)
print(ans)
```
