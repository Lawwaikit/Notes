二分查找最容易混乱的地方其实不是 `mid`，而是**你定义的搜索区间是什么，以及 `mid` 被排除后，区间应该怎么收缩**。

建议先记住一个核心原则：**`left` 和 `right` 表示“当前还可能存在答案的范围”，更新时必须保证答案不会被你提前排除。**

## 一、最常用的 Python 二分模板

### 模板 1：`while left <= right`

适合：**精确查找某个值**。

```python
def binary_search(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

这里的区间是：`[left, right]`， 也就是**左右边界都包含**， 所以只要 `left <= right`，区间里就还有元素需要检查。

## 二、`while left < right` 什么时候使用？

它通常用于：**最终把区间缩小到一个位置，然后这个位置就是答案候选**。

最典型的是“寻找第一个满足条件的位置”，也叫**左边界二分**。

例如：

```python
def lower_bound(nums, target):
    left = 0
    right = len(nums)

    while left < right:
        mid = (left + right) // 2

        if nums[mid] >= target:
            right = mid
        else:
            left = mid + 1

    return left
```

例如：

```python
nums = [1, 2, 2, 2, 5, 7]
target = 2
```

最终：

```python
left = right = 1
```

答案就是 `1`。

这里使用：

```python
while left < right:
```

因为循环的目的不是“检查每一个元素是否等于 target”，而是**不断缩小答案范围，直到只剩一个候选位置**。

因此可以简单记：

| 写法              | 常见用途                      |
| --------------- | ------------------------- |
| `left <= right` | 查找“某个具体值是否存在”             |
| `left < right`  | 查找“边界/最小值/最大值/第一个满足条件的位置” |

但这只是**常见情况，不是绝对规则**。真正决定 `while` 条件的是你采用的区间定义。

---

## 三、`mid` 有哪些写法？

最常见的是：

```python
mid = (left + right) // 2
```

它取的是**中间偏左的位置**。

还可以取“中间偏右”

```python
mid = (left + right + 1) // 2
```

例如：

```python
left = 2
right = 5

普通/偏左 mid：
(2 + 5) // 2 = 3

偏右 mid：
(2 + 5 + 1) // 2 = 4
```


这个区别在某些二分模板中非常重要，尤其是当你需要写：

```python
left = mid
```

的时候。

---

## 五、什么时候 `left = mid`？

这是二分最容易出错的地方。

假设：

```python
mid = (left + right) // 2
```

如果你写：

```python
left = mid
```

那么 **mid 没有被排除**。

所以必须保证下一轮还能继续缩小区间，否则可能死循环。

例如：

```
left = 3
right = 4

mid = (3 + 4) // 2
    = 3
```

如果：

```
left = mid
```

那么：

```
left = 3
right = 4
```

完全没变化。

下一轮还是：

```
mid = 3
```

于是死循环。

因此，如果你需要：

```
left = mid
```

通常应该使用**偏右的 mid**：

```
mid = (left + right + 1) // 2
```

这样：

```
left = 3
right = 4

mid = (3 + 4 + 1) // 2
    = 4
```

然后：

```
left = mid
```

变成：

```
left = 4
right = 4
```

区间成功缩小。

---

## 六、什么时候 `left = mid + 1`？

当你已经确定：

> `nums[mid]` 不可能是答案。

这时候可以放心把 `mid` 排除掉。

例如普通查找：

```
if nums[mid] < target:
    left = mid + 1
```

因为数组有序：

```
nums[mid] < target
```

说明 `mid` 以及它左边的所有元素都太小了。

所以答案一定在：

```
mid + 1 ~ right
```

因此：

```
left = mid + 1
```

---

## 七、什么时候 `right = mid - 1`？

同理。

当你确定：

> `nums[mid]` 不可能是答案。

例如：

```
if nums[mid] > target:
    right = mid - 1
```

因为：

```
nums[mid] > target
```

那么 `mid` 以及右边的元素都太大。

答案只能在：

```
left ~ mid - 1
```

所以：

```
right = mid - 1
```

---

## 八、什么时候 `right = mid`？

这代表：

> `mid` 仍然有可能是答案，所以不能排除 mid。

例如找第一个 `>= target` 的位置：

```
if nums[mid] >= target:
    right = mid
else:
    left = mid + 1
```

为什么不是：

```
right = mid - 1
```

因为：

```
nums[mid] >= target
```

只能说明 `mid` 满足条件，但我们要找的是**第一个满足条件的位置**。

所以 `mid` 本身可能就是答案。

例如：

```
nums = [1, 2, 2, 2, 5]
             ↑
            mid
```

如果 `mid` 指向第一个 `2`，你当然不能把它排除。

因此：

```
right = mid
```

---

## 九、把 `left/right` 更新规则彻底搞懂

其实只需要问自己一个问题：

> **`mid` 还有没有可能是答案？**

如果答案是**不可能**，就排除 `mid`：

```python
left = mid + 1
或者：
right = mid - 1
```

如果答案是**仍然可能**，就保留 `mid`：

```python
left = mid
或者
right = mid
```

可以这样记：

```python
排除 mid → +1 / -1
保留 mid → 不加不减
```

这是二分最核心的规则。

---

## 十、为什么有时候 `left = mid`，有时候 `left = mid + 1`？

看一个典型的“找最大满足条件的值”。

假设：

```
0 1 2 3 4 5 6 7 8
✓ ✓ ✓ ✓ ✓ ✗ ✗ ✗ ✗
```

我们想找最后一个 `✓`。

假设 `mid` 落在 `✓`：

```
✓ ✓ ✓ [✓] ✗ ✗ ✗
        ↑
       mid
```

那么 `mid` 可能就是答案。

所以：

```
left = mid
```

不能写：

```
left = mid + 1
```

因为可能把真正答案排除。

但如果 `mid` 落在 `✗`：

```
✓ ✓ ✓ ✓ [✗] ✗ ✗
        ↑
       mid
```

那么 `mid` 肯定不是答案。

因此：

```
right = mid - 1
```

这种情况下，经常使用：

```
mid = (left + right + 1) // 2
```

保证 `left = mid` 时不会死循环。

## 十一、你可以直接记住这 3 个模板

### 1. 查找具体值

```python
left = 0
right = len(nums) - 1

while left <= right:
    mid = (left + right) // 2

    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

return -1
```

这个模板的特点是：**`[left, right]` 是闭区间，mid 找到就结束，找不到就把 mid 排除。**

### 2. 找第一个满足条件的位置

```python
left = 0
right = len(nums)

while left < right:
    mid = (left + right) // 2

    if check(mid):
        right = mid
    else:
        left = mid + 1

return left
```

这个模板的特点是：**答案可能是 mid，所以满足条件时使用 `right = mid`，而不是 `mid - 1`。**

### 3. 找最后一个满足条件的位置

```python
left = 0
right = len(nums) - 1

while left < right:
    mid = (left + right + 1) // 2

    if check(mid):
        left = mid
    else:
        right = mid - 1

return right
```

这个模板的关键就是：**因为需要 `left = mid`，所以 `mid` 要取偏右，否则 `left = mid` 在 `left + 1 == right` 时可能死循环。**

---

## 十二、最后给你一个二分速记表

| 你的判断              | `mid` 是否可能是答案 | 更新                |
| ----------------- | ------------- | ----------------- |
| 答案一定在右边           | 否             | `left = mid + 1`  |
| 答案可能在右边，也可能就是 mid | 是             | `left = mid`      |
| 答案一定在左边           | 否             | `right = mid - 1` |
| 答案可能在左边，也可能就是 mid | 是             | `right = mid`     |

而 `mid` 的选择可以记成：

```python
# 普通/偏左 mid
mid = (left + right) // 2
# 偏右 mid
mid = (left + right + 1) // 2
```

**最重要的一句话：先确定 `mid` 是否可能是答案，再决定 `+1/-1`；如果保留 `mid`，再考虑是否需要偏右 `mid` 防止死循环。**
