遇到这种连续最长区间，使用双指针，这两题的规律
1. 初始化 l, r=0, 0
2. 外层循环 `while r<n`: 然后先移动一次r：`r+=1`
3. 内存循环 `while r < n and xxx(判断是否符合条件)` 然后连续移动r
4. 3的循环结束后，r-1为上一个连续区间的右闭端点 区间长度，可以结算一次计算，比如max(xx)
5. 循环的最后l=r，此时l为新的区间的左闭端点

## 题目1：[华为OD机试新系统真题 - 最长不连续子串](https://blog.csdn.net/qq_45776114/article/details/163527171)


```python
    ans = 0
    l, r = 0, 0
    while r < n:
        r += 1
        while r < n and abs(arr[r] - arr[r-1]) > 1:  # 连续移动r
            r += 1
        curr_len = r-l  # 此时r-1是连续的右闭端点，所以长度=r-l
        ans = max(ans, curr_len)
        l = r

    return ans
```
