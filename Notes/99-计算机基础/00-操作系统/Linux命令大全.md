## 查找

最核心、最常用的是 **`find`** 和 **`locate`**。此外，针对“可执行命令”的查找，**`which`** 和 **`whereis`** 也经常用到。
### 查找文件
`find`：功能最强大的实时搜索  
它会遍历磁盘目录树，支持按文件名、类型、大小、修改时间等复杂条件组合查找，结果实时准确。
- **按名查找**：`find /path -name "*.log"`（区分大小写）；`-iname` 则不区分。
- **按类型查找**：`-type f` 找普通文件，`-type d` 找目录。
- **按大小查找**：`-size +100M` 找大于 100MB 的文件。
- **按时间查找**：`-mtime -7` 找最近 7 天内修改过的文件。
- **限制深度**：`-maxdepth 2` 只在当前目录及下一层子目录中搜索，避免全盘扫描过慢。

`locate`：基于数据库的极速查找  
它搜索的是系统预建的文件名数据库，速度远快于 `find`，但**结果可能不是实时的**（新创建的文件可能搜不到）
- **基本用法**：`locate nginx.conf`（只要路径中包含该字符串即返回）。
- **更新数据库**：如果找不到刚创建的文件，通常需要运行 `sudo updatedb` 手动刷新数据库。

###  定位“可执行命令”的专用命令

如果你找的是 `python`、`ls` 这类**可以执行的程序**，而不是普通的文档或配置文件，用下面两个命令更直
### 查找文件中的内容
#### 核心命令：grep

**基本语法**：`grep [选项] "要查找的内容" 文件名`

- **在单个文件中查找**：`grep "error" app.log`。这会列出 `app.log` 中所有包含 "error" 的行。
- **在当前目录递归查找**：这是最常用的场景。使用 `-r`（或 `-R`）可以搜索目录下的所有文件及其子目录：`grep -r "error" /var/log/`。
- **忽略大小写**：加 `-i`，例如 `grep -ri "error" /var/log/`，这样 "Error" 和 "ERROR" 也会被匹配到。
- **显示行号**：加 `-n`，方便定位内容在文件中的位置：`grep -rn "error" /var/log/`。
- **只列出文件名**：如果你只关心哪些文件包含该内容，而不想看具体行，用 `-l`：`grep -rl "error" /var/log/`。

####  进阶用法：结合 `find` 精确范围

如果你只想在**特定类型**的文件（例如所有 `.py` 文件）中搜索内容，可以结合之前学过的 `find` 命令。`find` 负责筛选文件，`grep` 负责搜索内容。

**示例**：只在当前目录的 Python 文件中查找 "import"：

```bash
find . -name "*.py" -exec grep -n "import" {} \;

或者使用管道和 `xargs`（对包含空格的文件名更安全）：
find . -name "*.py" -print0 | xargs -0 grep -n "import"
```


## 拷贝
Linux 拷贝文件最核心的命令是 **`cp`**。根据拷贝的对象不同（普通文件、目录、远程服务器），还会用到 **`scp`** 和 **`rsync`**。

### 📄 本地拷贝：`cp`

**基本用法**：`cp 源文件 目标路径`

- **拷贝文件**：`cp file.txt /tmp/`（把文件复制到 /tmp 目录下）
- **拷贝并重命名**：`cp file.txt /tmp/newfile.txt`
- **拷贝目录**：必须加 `-r`（递归），例如 `cp -r mydir /tmp/`
- **保留文件属性**：加 `-p`，会保留权限、时间戳、所有者等信息，常用于备份：`cp -p file.txt /backup/`
- **强制覆盖不提示**：加 `-f`；反之，如果希望覆盖前有提示，可以用 `-i`。

**注意**：`cp` 默认会直接覆盖同名文件且不提示（除非目标文件只读或配置了别名），操作前务必确认目标路径。

### 🌐 远程拷贝：`scp`

用于在本地和远程服务器之间，或两台远程服务器之间拷贝文件，基于 SSH 协议，安全且无需额外配置。

- **本地传到远程**：`scp file.txt user@192.168.1.10:/home/user/`
- **远程拉到本地**：`scp user@192.168.1.10:/home/user/file.txt ./`
- **拷贝整个目录**：加 `-r`，例如 `scp -r mydir user@192.168.1.10:/home/user/`
- **指定端口**：如果 SSH 不是默认的 22 端口，用 `-P`（大写），例如 `scp -P 2222 file.txt user@host:/path/`
