## Python深拷贝和浅拷贝
核心区别：浅拷贝只复制外层对象，深拷贝会递归复制内部嵌套对象。


## Python面向对象的特点：封装、继承、多态
### 1. 封装

封装是将数据和操作数据的方法组织在类中，并通过访问约定控制外部对数据的使用。

### 2. 继承

继承是子类复用父类的属性和方法，并且可以扩展或重写父类的行为。

### 3. 多态

多态是不同类型的对象可以通过相同的接口执行各自不同的行为。


## Python的数据结构：可变类型和不可变类型

可变与不可变描述的是对象创建后，能否修改其自身内容，而不是变量能否重新赋值。

| 类型   | 常见数据类型               | 是否可变  |
| ---- | -------------------- | ----- |
| 数值类型 | `int`、`float`、`bool` | 不可变   |
| 字符串  | `str`                | 不可变   |
| 元组   | `tuple`              | 不可变容器 |
| 列表   | `list`               | 可变    |
| 字典   | `dict`               | 可变    |
| 集合   | `set`                | 可变    |

### Python函数作用域
Python 查找变量时遵循 LEGB 顺序，即从当前作用域开始，逐层向外查找。

|规则|作用域|说明|
|---|---|---|
|L|Local|当前函数内部的局部作用域|
|E|Enclosing|外层嵌套函数的作用域|
|G|Global|当前模块的全局作用域|
|B|Built-in|Python 内置作用域，例如 `len()`、`print()`|
#### 1. 局部变量

在函数内部赋值的变量，通常属于当前函数的局部变量，函数外部不能直接访问。
#### 2. 全局变量

在模块顶层定义的变量属于全局变量，可以在函数内部读取。

#### `global` 和 `nonlocal` 的区别

`global` 用于声明操作的是模块级全局变量，`nonlocal` 用于声明操作的是最近一层外部函数中已经存在的变量。
## Python值传递和引用传递
Python 的参数传递通常称为“对象引用传递”或“共享对象传递”（call by sharing），并不是传统意义上的纯值传递，也不是传统意义上的引用传递。
