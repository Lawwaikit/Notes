## Python 修饰器（Decorator）详解

### 一、什么是修饰器

修饰器是 Python 中一种**在不修改原函数代码的前提下，动态增强函数功能**的语法糖。本质上，修饰器是一个**接收函数作为参数并返回新函数的高阶函数**。

```python
@decorator
def func():
    pass
```
等价于：
```python
func = decorator(func)
```

---

### 二、基本用法

#### 1. 最简单的修饰器

```python
def my_decorator(func):
    def wrapper():
        print("函数执行前")
        func()
        print("函数执行后")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
# 输出：
# 函数执行前
# Hello!
# 函数执行后
```

#### 2. 带参数的函数（使用 `*args, **kwargs`）

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}，参数: {args}, {kwargs}")
        result = func(*args, **kwargs)
        print(f"返回值: {result}")
        return result
    return wrapper

@my_decorator
def add(a, b):
    return a + b

add(3, 5)
# 调用 add，参数: (3, 5), {}
# 返回值: 8
```

#### 3. 保留原函数元信息（`functools.wraps`）

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)          # 保留原函数的 __name__、__doc__ 等
    def wrapper(*args, **kwargs):
        """wrapper 的文档"""
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def greet():
    """打招呼函数"""
    print("Hi")

print(greet.__name__)  # greet（若无 @wraps 则为 wrapper）
print(greet.__doc__)   # 打招呼函数
```

### 三、进阶用法

#### 1. 带参数的修饰器（三层嵌套）

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def say(msg):
    print(msg)

say("你好")
```


等价于
```python
# 第一步：先调用 repeat(times=3)，得到一个"真正的修饰器"
real_decorator = repeat(times=3)
# 第二步：再用这个修饰器修饰 say_hello
say_hello = real_decorator(say_hello)

say_hello()
# 你好
# 你好
# 你好
```
所以需要三层

#### 2. 类作为修饰器

```python
class CountCalls:
    def __init__(self, func):
        self.func = func
        self.count = 0

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"第 {self.count} 次调用")
        return self.func(*args, **kwargs)

@CountCalls
def hello():
    print("Hello")

hello()  # 第 1 次调用 / Hello
hello()  # 第 2 次调用 / Hello
```

#### 3. 多个修饰器叠加

```python
@decorator_a
@decorator_b
def func(): ...
# 等价于：func = decorator_a(decorator_b(func))
# 执行顺序：先 decorator_b 包装，再 decorator_a 包装（调用时 a 在外层）
```

### 四、常见实用场景

#### 1. 计时器

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.perf_counter()-start:.4f}s")
        return result
    return wrapper

@timer
def slow_task():
    time.sleep(1)
```

#### 2. 日志记录

```python
def log(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[LOG] 调用 {func.__name__}({args}, {kwargs})")
        return func(*args, **kwargs)
    return wrapper
```

#### 3. 权限校验

```python
def require_login(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if not user.get("is_login"):
            raise PermissionError("请先登录")
        return func(user, *args, **kwargs)
    return wrapper

@require_login
def view_profile(user):
    print(f"欢迎 {user['name']}")

view_profile({"is_login": True, "name": "Alice"})
```

#### 4. 缓存（记忆化）

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
```

### 五、关键要点总结

| 要点 | 说明 |
|------|------|
| 本质 | `func = decorator(func)` |
| 核心结构 | 外层函数接收 `func`，内层 `wrapper` 调用它 |
| 传参处理 | 用 `*args, **kwargs` 适配任意参数 |
| 元信息保留 | 用 `@functools.wraps(func)` |
| 带参修饰器 | 三层嵌套：`decorator(args) -> decorator -> wrapper` |
| 执行顺序 | 多个修饰器时，**离函数近的先包装**，调用时**外层先执行** |
| 常见应用 | 日志、计时、权限、缓存、重试、事务等 AOP 场景 |

修饰器的核心思想是**面向切面编程（AOP）**，把横切关注点（日志、权限、性能等）从业务逻辑中抽离出来，让代码更简洁、可复用。
